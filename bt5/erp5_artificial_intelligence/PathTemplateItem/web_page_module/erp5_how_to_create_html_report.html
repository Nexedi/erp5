# Guide: Writing HTML Content in ERP5 for PDF Export This guide documents the HTML conventions expected by ERP5's book/PDF export feature when turning a Web Page's content into a formatted "book" (cover page, header/footer, table of contents, tables/figures/references overview, PDF pagination). Write your report's HTML content following these rules, then use the export-as-book action available on the Web Page (HTML preview first, then PDF for the final output). Useful export options: include a table of contents, include a tables/figures/references overview, embed linked documents or reports (see below), and override the cover-page metadata (title, version, reference, author, organisation). The cover page itself is auto-generated - never author cover-page HTML by hand. ## 1. Headings and Table of Contents Use plain `

Do not insert the table of contents yourself; it is generated automatically from your headings and placed right before your content. ## 2. Images Reference images by their ERP5-relative path, not an absolute `http(s)://` URL or a `data:` URI - non-local images are not validated and will render a broken-image warning if they can't be resolved. The link's visible text decides the category: `RD` = Referenced Document, `AD` = Applicable Document, anything else (e.g. `ERP`) = Abbreviation (the text itself becomes the stored abbreviation). The `title` attribute carries up to three `;`-separated fields (full title; number/description; version). ```html [RD] [AD] [ERP] ``` Reusing the same `href` keeps the same reference number. A plain link *not* wrapped in brackets (e.g. `document`) is left untouched. ## 5.
