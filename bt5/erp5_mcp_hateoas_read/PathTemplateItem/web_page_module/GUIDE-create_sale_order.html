> OSOE Tutorial: https://osoe-project.nexedi.com/lesson/user-Howto.Create.Sale.Orders/view ### Prerequisites - A validated client (Organisation or Person) in the system - Optionally, a validated Sale Trade Condition - Validated Products for order lines ### Steps 1. **Create the Sale Order** ``` erp5_create(relative_url="sale_order_module", portal_type="Sale Order") ``` → Note the `relative_url`. 2. **Search for the client** ``` erp5_search(relative_url="organisation_module", query='title:"Client Name"', select_list=["title", "default_address_city"]) ``` 3. **Search for Trade Conditions** (optional but recommended) ``` erp5_search(relative_url="sale_trade_condition_module", query='validation_state:"validated"', select_list=["title", "reference"]) ``` 4. **Fill in the Sale Order header** ``` erp5_write(relative_url="<new_url>", field_values={ "field_my_title": "Sale Order Title", "field_my_destination_section_title": "Client Organisation", "field_my_destination_title": "Client Organisation", "field_my_source_title": "Your Organisation", "field_my_specialise_title": "Standard Sale Terms", "field_my_source_decision_title": "Seller Contact Name", "field_my_destination_decision_title": "Buyer Contact Name", "field_my_order": "normal", "field_my_delivery_mode": "air", "field_my_incoterm": "cpt" }) ``` - Use the organisation created in Session 1 for `source_title`. - `source_decision_title` — seller's contact person (RelationStringField). - `destination_decision_title` — buyer's contact person (RelationStringField). - `order` — priority (ListField: `"urgent"`, `"normal"`, `"low"`). - `delivery_mode` — shipping mode (ListField). Check valid choices with `erp5_read`. - `incoterm` — international commercial terms (ListField). 5. **Apply Sale Trade Condition** (if set) After setting `specialise_title`, check if there is an "Apply Sale Trade Condition" action available: ``` erp5_read(relative_url="<new_url>") ``` Look in the `actions` or `workflows` for an apply action. This auto-fills currency, supplier profile, and payment terms from the trade condition. 6. **Set dates** (write separately to avoid date expansion issues) ``` erp5_write(relative_url="<new_url>", field_values={ "field_my_start_date": "2025-01-15", "field_my_stop_date": "2025-12-31" }) ``` 7. **Fill Profile tab** (on `profile_view`, requires `form_id`) ``` erp5_write(relative_url="<new_url>", field_values={ "field_my_source_administration_title": "Your Organisation", "field_my_destination_administration_title": "Client Organisation" }, form_id="SaleOrder_viewProfile", skip_validation=True) ``` Note: The view name is `profile_view` but the form_id is `SaleOrder_viewProfile`. ``` - `source_administration_title` — invoicing entity on the seller side. - `destination_administration_title` — invoicing entity on the buyer side. 8. **Create Sale Order Lines** (one per product) ``` erp5_create(relative_url="<sale_order_url>", portal_type="Sale Order Line") ``` ``` erp5_write(relative_url="<line_url>", field_values={ "field_my_title": "Product A", "field_my_resource_title": "Product A", "field_my_reference": "PROD-A-001", "field_my_quantity": "10", "field_my_price": "100.00", "field_my_quantity_unit": "unit/piece" }) ``` Repeat for each product/service. - `reference` — line reference / product code. - `quantity_unit` — must match the product's quantity unit. 9. **Confirm the Sale Order** (when ready) ``` erp5_action(relative_url="<sale_order_url>", action_name="confirm_action") ``` ### Key Fields Reference (Sale Order) | Field | Key | Type Condition" action after setting the trade condition. - `source_title` (Sender/Provider) is **required** before confirm — set it explicitly. - `start_date` (Shipping Date) is **required** — write dates in a separate call. - `source_section` = supplier (billing), `destination_section` = client (billing). - Available workflow: draft → plan/offer/order → confirm.
