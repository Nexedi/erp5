> OSOE Tutorial: https://osoe-project.nexedi.com/lesson/user-Howto.Create.and.Manage.Products/view ### Prerequisites - Access to `product_module` (verify with `erp5_discover`) ### Steps 1. **Create the Product** ``` erp5_create(relative_url="product_module", portal_type="Product") ``` → Note the `relative_url`. 2. **Discover all editable fields** ``` erp5_read(relative_url="<new_url>", all_editable=True) ``` 3. **Fill in product details** (main `view`) ``` erp5_write(relative_url="<new_url>", field_values={ "field_my_title": "Product Name", "field_my_reference": "PROD-001", "field_my_quantity_unit_list": "unit/piece", "field_my_use_list": "trade/sale", "field_my_product_line": "service", "field_my_base_contribution_list": "base_amount/taxable" }) ``` - `base_contribution_list` — defines tax applicability. Use `"base_amount/taxable"` for products subject to tax. - `individual_variation_base_category_list` — leave blank for simple products; set for products with variations (advanced topic). 4. **Set sale pricing** (on `sale_price_view`, requires `form_id`) ``` erp5_write(relative_url="<new_url>", field_values={ "field_my_sale_supply_line_base_price": "100.00", "field_my_sale_supply_line_price_currency": "currency_module/EUR", "field_my_sale_supply_line_priced_quantity": "1.0" }, form_id="Resource_viewDefaultSaleSupplyLine", skip_validation=True) ``` - `priced_quantity` — the quantity for which the base price applies (e.g. `"1.0"` means the price is per unit). 5. **Set purchase pricing** (on `purchase_price_view`, requires `form_id`) ``` erp5_write(relative_url="<new_url>", field_values={ "field_my_purchase_supply_line_base_price": "80.00", "field_my_purchase_supply_line_price_currency": "currency_module/EUR", "field_my_purchase_supply_line_priced_quantity": "1.0" }, form_id="Resource_viewDefaultPurchaseSupplyLine", skip_validation=True) ``` 6. **Validate the Product** ``` erp5_action(relative_url="<new_url>", action_name="validate_action") ``` ### Key Fields Reference (main view) | Field | Key | Type | Notes | |---|---|---|---| | Title | `field_my_title` | StringField pricing is on the `sale_price_view` tab — writing requires `form_id="Resource_viewDefaultSaleSupplyLine"`. - Purchase pricing is on `purchase_price_view` — writing requires `form_id="Resource_viewDefaultPurchaseSupplyLine"`. - Quantity unit uses `my_quantity_unit_list` (ParallelListField), not `my_quantity_unit`. - Variations (size, colour, etc.) — see `erp5_guide(tutorial="create_product_with_variations")` for the complete variation workflow including MatrixBox pricing.
