> OSOE Tutorial: https://osoe-project.nexedi.com/lesson/user-Howto.Create.Trade.Conditions/view ### Prerequisites - Access to `sale_trade_condition_module` (verify with `erp5_discover`) - Your organisation created in Session 1 (with a validated Bank Account) ### Steps 1. **Create the Trade Condition** ``` erp5_create(relative_url="sale_trade_condition_module", portal_type="Sale Trade Condition") ``` → Note the `relative_url`. 2. **Discover editable fields** ``` erp5_read(relative_url="<new_url>", all_editable=True) ``` 3. **Fill in trade condition details** (main `view`) ``` erp5_write(relative_url="<new_url>", field_values={ "field_my_title": "Standard Sale Terms", "field_my_reference": "STC-001", "field_my_description": "Standard sale terms description", "field_my_price_currency": "currency_module/EUR", "field_my_incoterm": "cpt", "field_my_comment": "VAT", "field_my_source_section_title": "Your Organisation", "field_my_specialise_title_list": ["Default Trade Business Process"] }) ``` - Use the organisation created in Session 1 for `source_section_title`. - The `specialise_title_list` links to a Business Process — this is **critical** for the order→packing list→invoice chain to work. Search `business_process_module` to find available ones. 4. **Create a Payment Condition sub-object** ``` erp5_create(relative_url="<trade_condition_url>", portal_type="Payment Condition") ``` ``` erp5_write(relative_url="<payment_condition_url>", field_values={ "field_my_title": "30 Days Net from Invoice", "field_my_payment_term": "30", "field_my_trade_date": "trade_phase/trade/invoicing", "field_my_payment_mode": "wire_transfer", "field_my_efficiency": "1.0" }, skip_validation=True) ``` For split payments, create multiple Payment Conditions with different `efficiency` values (e.g. 0.2 for 20% advance, 0.8 for 80% balance). 5. **Set supplier profile** (on `view_profile` tab, requires `form_id`) ``` erp5_write(relative_url="<new_url>", field_values={ "field_my_source_title": "Your Organisation", "field_my_source_decision_title": "Your Organisation", "field_my_source_administration_title": "Your Organisation" }, form_id="SaleTradeCondition_viewProfile", skip_validation=True) ``` These fields define who is the sender/provider, seller, and invoice sender. Use the organisation created in Session 1. Then **set the Payee** (supplier's bank account) — requires saving first so the bank account choices populate: ``` erp5_read(relative_url="<new_url>", view="view_profile") ``` Check `my_source_payment.valid_choices` for available bank accounts, then: ``` erp5_write(relative_url="<new_url>", field_values={ "field_my_source_payment": "organisation_module/<org_id>/<bank_account_id>" }, form_id="SaleTradeCondition_viewProfile", skip_validation=True) ``` The supplier organisation must have a validated Bank Account for this to work. 6. **Validate the Trade Condition** ``` erp5_action(relative_url="<new_url>", action_name="validate_action") ``` ### Key Fields Reference (main view) | Field | Key | Type | Notes | |---|---|---|---| | Title | `field_my_title` | StringField default terms for orders (currency, payment, parties). - **Must** link to a Business Process (`specialise_title_list`) for the sale→delivery→invoice chain. - `specialise_title_list` is a MultiRelationStringField — pass value as a **list**: `["Title"]`. - Payment terms use Payment Condition sub-objects (create via `erp5_create` on the trade condition). - Profile tab sets the supplier roles — these auto-fill on Sale Orders that use this condition. - When applied to a Sale Order, they auto-fill source_section, currency, sender, etc.
